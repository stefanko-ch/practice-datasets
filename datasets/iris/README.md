# Iris – sepal and petal measurements of 150 flowers

Fisher's 1936 iris data: four measurements of 50 flowers each of three iris species. Exported from `px.data.iris()`.

| | |
|---|---|
| Download | [`iris.csv`](https://github.com/stefanko-ch/practice-datasets/releases/download/v1/iris.csv) (4 KB) |
| Rows | 150 |
| Source | [https://archive.ics.uci.edu/dataset/53/iris](https://archive.ics.uci.edu/dataset/53/iris) |
| License | Public domain (Fisher, 1936) |

## Columns

| Column | Meaning |
|---|---|
| `sepal_length / sepal_width / petal_length / petal_width` | Measurements, cm |
| `species` | setosa, versicolor, virginica |
| `species_id` | 1, 2, 3 |
