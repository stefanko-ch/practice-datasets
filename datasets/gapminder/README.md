# Gapminder – life expectancy, population and GDP per capita, 142 countries 1952–2007

One row per country and 5-year step (1952, 1957, … 2007): continent, life expectancy, population and GDP per capita (inflation-adjusted USD), plus ISO codes. Exported from `px.data.gapminder()`.

| | |
|---|---|
| Download | [`gapminder.csv`](https://github.com/stefanko-ch/practice-datasets/releases/download/v1/gapminder.csv) (99 KB) |
| Rows | 1,704 |
| Source | [https://www.gapminder.org/data/](https://www.gapminder.org/data/) |
| License | CC BY 4.0 (Gapminder), distributed with plotly.py (MIT) |

## Columns

| Column | Meaning |
|---|---|
| `country / continent` | Country and continent |
| `year` | 1952–2007 in steps of 5 |
| `lifeExp` | Life expectancy at birth, years |
| `pop` | Population |
| `gdpPercap` | GDP per capita, inflation-adjusted USD |
| `iso_alpha / iso_num` | ISO 3166 country codes |
