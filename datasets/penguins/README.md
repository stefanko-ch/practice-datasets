# Palmer penguins – body measurements of 344 penguins

Bill length and depth, flipper length, body mass and sex of three penguin species (Adelie, Chinstrap, Gentoo) on three islands of the Palmer Archipelago, Antarctica. Some values are missing on purpose (NaN). Exported from seaborn's `load_dataset("penguins")`.

| | |
|---|---|
| Download | [`penguins.csv`](https://github.com/stefanko-ch/practice-datasets/releases/download/v1/penguins.csv) (15 KB) |
| Rows | 344 |
| Source | [https://allisonhorst.github.io/palmerpenguins/](https://allisonhorst.github.io/palmerpenguins/) |
| License | CC0 (palmerpenguins) |

## Columns

| Column | Meaning |
|---|---|
| `species` | Adelie, Chinstrap or Gentoo |
| `island` | Biscoe, Dream or Torgersen |
| `bill_length_mm / bill_depth_mm` | Bill (beak) length and depth, mm |
| `flipper_length_mm` | Flipper length, mm |
| `body_mass_g` | Body mass, g |
| `sex` | Male / Female (some missing) |
