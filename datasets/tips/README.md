# Restaurant tips – 244 bills with tip, day and time

Total bill, tip, sex and smoker status of the payer, weekday, lunch/dinner and party size for 244 restaurant bills. The classic small dataset of seaborn and Plotly Express (`px.data.tips()`, identical).

## Columns

| Column | Meaning |
|---|---|
| `total_bill / tip` | Bill and tip, USD |
| `sex / smoker` | Payer |
| `day` | Thur, Fri, Sat, Sun |
| `time` | Lunch / Dinner |
| `size` | Number of people at the table |
