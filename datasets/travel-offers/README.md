# Travel offers – nested JSON (synthetic)

5 000 package-holiday offers to Cyprus in a deeply nested JSON structure (`root.Page[].Position…`): hotel, destination, package, price. Typical of web/API exports – needs `explode` and dot notation. Hotels and tour operators are fictional, places are real.
