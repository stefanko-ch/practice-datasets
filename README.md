# practice-datasets

Open and synthetic datasets for data-engineering exercises, recipes and courses – usable with Databricks,
DuckDB, dbt, the Nexus stack or any other tool that reads Parquet, CSV, JSON, XML, YAML or Excel.

- **In this repository:** one folder per dataset under [`datasets/`](datasets/) with a description, the meaning of the
  columns, source, license and a sample extract (the first rows as `sample.*`).
- **The full data** is published as release assets – **one file per dataset**, so you download only what you need.
  Single files are provided as they are (Parquet, CSV, JSON, XLSX); datasets made of several files as ZIP.

```bash
curl -LO https://github.com/stefanko-ch/practice-datasets/releases/download/v1/zurich_weather_hourly.csv
```

In **Databricks Free Edition** the download works from a notebook or job, because GitHub is on the allow-list of its
outbound firewall (many other sites, e.g. `data.stadt-zuerich.ch`, are blocked).

## Real vs. synthetic data

The Zurich, Basel, AdventureWorks, world and UCI/ggplot2 datasets are real open data under the listed licenses.
Datasets marked *synthetic* replace files of unclear origin from earlier course material: they are generated by
[`scripts/generate_synthetic.py`](scripts/generate_synthetic.py) with a fixed seed and keep the structure, column
names and deliberate quirks of the originals, so existing exercises keep working.

## Maintaining the datasets

The raw files live locally in `data/` (gitignored). To rebuild everything:

```bash
uv run --with openpyxl scripts/generate_synthetic.py                       # synthetic datasets -> data/synthetic/
uv run --with pandas --with pyarrow --with openpyxl scripts/build_release.py   # dist/ + datasets/ + catalog above
gh release create v1 dist/* --title "v1" --notes "Initial dataset collection"
```

For new data (e.g. updated Zurich counts) refresh `data/`, rebuild and publish a new release (`v2`, set `RELEASE` in
`build_release.py`) – links to `v1` keep working.
